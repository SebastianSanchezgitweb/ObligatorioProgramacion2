# Sistema de Gestión de Eventos

Aplicación desarrollada en C# con SQL Server para la gestión de eventos corporativos y sociales.

## Funcionalidades
- Registro de clientes
- Registro de empleados
- Gestión de servicios contratados
- Creación y administración de eventos
- Manejo de base de datos relacional
- Operaciones CRUD completas

## Objetivo
Organizar y optimizar la gestión de eventos mediante el manejo estructurado de datos y procesos.

## Tecnologías utilizadas
- C#
- SQL Server
